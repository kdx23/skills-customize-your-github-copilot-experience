# 📘 Assignment: Algorithmic Problem Solving

## 🎯 Objective

Practice breaking problems into clear steps and implementing efficient Python solutions using lists and dictionaries. By the end, you will solve real programming challenges and compare different approaches.

## 📝 Tasks

### 🛠️ Build a Frequency Counter

#### Description
Write a program that analyzes a list of words and counts how often each word appears. Start with a loop-based solution, then improve it using a dictionary.

#### Requirements
Completed program should:

- Implement a function that returns word frequencies for a given list of strings.
- Use a dictionary where keys are words and values are counts.
- Print the top 3 most common words from a sample list.


### 🛠️ Solve a Pair-Sum Challenge

#### Description
Create a function that finds two numbers in a list that add up to a target value. Compare a basic nested-loop approach with a faster dictionary-based approach.

#### Requirements
Completed program should:

- Implement one solution using nested loops and one solution using a dictionary.
- Return the indices of the two matching numbers when a pair exists.
- Display both solutions on the same test input and explain which is more efficient.
